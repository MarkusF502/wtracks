# Capturas do Playback 8.6.2 no iPhone (enviadas pelo usuário, 2026-10)

A versão é mais nova que a do binário analisado (8.5.3), e a interface está em português. Valem como referência de
aparência e de fluxo. Quando divergirem do binário, o comportamento do binário prevalece.

| Arquivo | O que mostra |
|---|---|
| 01 | Promoção "Demo Setlist" (nuvem/assinatura, fora do escopo) |
| 02, 03 | Tela vazia. O título é o nome do repertório ("Meu Repertório do Playback"), o tempo/compasso aparece como "——" e o relógio como "--:--". Na faixa de músicas: "Abrir Repertório de Demonstração" e "+ Novo Repertório". O mixer vazio mostra só faders com "S". O botão ≡ tem um ponto vermelho de novidade |
| 04 | Botão do console em "waveform" (o painel de baixo vira a waveform) |
| 05, 07, 08 | Modo de edição: EDITAR vira "PRONTO" e o título mostra "120 BPM 4/4 (Repertório / Mapa da Música)". No rodapé, uma **barra de modos de edição** rolável: Repertório / Mapa da Música · Gatilhos MIDI · Automação · Mapeamento MIDI · Mapeamento do Teclado · Seções da Música do Cloud · SMPTE. A **música só de click** ("120 BPM 4/4 (F)", cartão com ícone de metrônomo laranja) tem (−) e (…). "+ Adicionar Música" fica ao lado |
| 05, 08, 09 | Mixer de uma música só de click: fader "Click" com "<" que abre o grupo **Acento / 1/4 / 1/8 / 1/16** (fundo mais claro) e o fader "Guia" |
| 06 | Repertório novo ("teste") no modo de edição, só com "+ Adicionar Música" |
| 09 | Dica de primeiro uso (balão azul "NOVO", "Administrar seus Repertórios", botão ENTENDI) apontando para o botão de setlists |
| 10 | "Novo Repertório": Nome, Data (outubro 18, 2026), Tipo de Culto, Horário dos Cultos, botão Criar |
| 11 | Pad Player: fader "Pad ▶", cabeçalho do pad com "LINK", grade de 12 tons (Db Eb Gb Ab Bb B / C D E F G A). No console, "PAD PLAYER" e os pontos de página (⋮) mostram 3 painéis |
| 12 | Menu ≡ como painel lateral à direita: cartão de novidade, "Playback Intro v8.6.2", Ajustes, Notificações, Playback Sync |
